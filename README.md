# 后世 Afterlife — Backrooms 无限迷宫生存游戏

> 你被困在了"后世"——一个发黄墙纸、潮湿地毯、荧光灯嗡嗡作响的无限迷宫。

Windows 3D 第一人称生存游戏（Win32 + OpenGL 3.3），用 C++ 从零实现。

## 玩法

- **真实光影**：荧光灯程序化动态照明 + 手电筒实时阴影（PCF 软阴影）
- **真实物理**：重力、跳跃、天花板限制；禁飞、禁穿墙（AABB 碰撞）
- **无限迷宫**：确定性哈希程序化生成，随玩家无限延伸，可存档
- **人形建模**：第一人称可见双手、五指、双腿双脚；第三人称/上帝视角可看全身
- **生存数值**：生命 / 理智 / 饥饿 / 口渴 / 体力；荧光灯恢复理智，黑暗消耗理智
- **背包系统**：40 格永久背包（E 开/关，左键拿起/放下，右键使用，Q 选中/丢弃），随等级扩容
- **等级系统**：吃腐肉 +1 经验，100 经验升 1 级，背包 +1 格
- **物品**：银杏水（杏仁水）＝口渴+50% / 理智+20 / 生命+2 / 饥饿+1%；腐肉＝饥饿+10% / 生命+4 / 理智-1 / 经验+1
- **AKM 步枪**：聊天框输入 `/giop @s akm` 给自己发枪；左键射击、R 换弹、有曳光与枪口火光
- **聊天 / 联机**：T 打开聊天；`/help` 查看指令；LAN 广播 + STUN 内网穿透，好友输 `/join IP:端口` 进入同一迷宫一起游玩和聊天

## 构建（Windows）

需要 MinGW-w64（llvm-mingw / mingw-w64）。

```sh
# 资源
x86_64-w64-mingw32-windres -i resource.rc -o resource.o --input-format=rc --output-format=coff -I.
# 编译
x86_64-w64-mingw32-g++ -O2 -std=c++17 -static -o 后世.exe houshi.cpp resource.o \
    -lopengl32 -lgdi32 -luser32 -lwinmm -lws2_32 -mwindows
```

启动后进入主菜单：**开始新游戏**（输入角色名）/ **继续游戏** / **退出游戏**。
游戏目录自动生成：`save.dat`（存档）、`sfx_*.wav`（音效）、`startup.log`（启动诊断）。

## 文件说明

- `houshi.cpp` — 主源码（由 part0~part8 组装，`assemble.py` 一键重组）
- `part0.cpp ~ part8.cpp` — 分模块源码（全局/数学/网格/贴图/迷宫/物理/音频/联机/逻辑/HUD/主循环）
- `linux_test.cpp` — 逻辑回归测试（迷宫连通性、禁飞、禁穿墙、出生点、射线）9/9 PASS
- `icon.ico` / `resource.rc` / `make_icon.py` — 程序图标
- `font.ttc` — 文泉驿正黑字体（界面文字回退）
- `autotest.cfg` — 自检脚本（放入游戏目录后自动执行并写 `test.log`）

## 联机（自动内网穿透）

1. 双方都启动游戏并进入世界
2. 菜单/游戏内查看自己的联机码（公网 IP:端口，自动 STUN 探测）
3. 一方在聊天框输入 `/join 对方的公网IP:端口`
4. 双方自动互相打洞连接，即可同屏游玩 + 聊天
