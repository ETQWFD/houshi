这是什么

你被困在后世——发黄墙纸、潮湿地毯、荧光灯嗡鸣作响的无限迷宫。 没有出口，没有边界。寻找杏仁水恢复理智，警惕腐肉侵蚀精神，在黑暗与荧光之间活下去。

核心特性

  • 真实光影：荧光灯动态照明 + 手电筒实时软阴影（PCF）
  • 真实物理：重力 / 跳跃 / 天花板；禁飞、禁穿墙（AABB 碰撞）
  • 无限程序化迷宫：确定性哈希生成，无限延伸，F9 随时存档
  • 人形建模：第一人称可见双手五指、双腿双脚；第三人称 / 上帝视角（F5 切换）
  • 生存五维：生命 / 理智 / 饥饿 / 口渴 / 体力
  • 永久背包：默认 40 格，E 开/关，左键拖放、右键使用、Q 丢弃；吃肉升级 +1 格
  • 物品：银杏水（杏仁水）与腐肉，均有进食动作与音效
  • AKM 步枪：聊天框输入 /giop @s akm 发枪，射击 / 换弹 / 曳光 / 枪口火光
  • 真联机：LAN 广播 + STUN 自动内网穿透，/join IP:端口 与好友同迷、同聊

联机（自动内网穿透）

  • 双方进入游戏后，查看自己的联机码（自动 STUN 探测公网 IP:端口）
  • 一方在聊天框输入 /join 对方的公网IP:端口
  • 自动互相打洞建立直连，即可同屏游玩 + 聊天

构建

Windows 下需要 MinGW-w64（llvm-mingw 或 mingw-w64）：

x86_64-w64-mingw32-windres -i resource.rc -o resource.o --input-format=rc --output-format=coff -I.
x86_64-w64-mingw32-g++ -O2 -std=c++17 -static -o 后世.exe houshi.cpp resource.o \
    -lopengl32 -lgdi32 -luser32 -lwinmm -lws2_32 -mwindows

仓库内附 assemble.py（重组 part0~part8 源码）、linux_test.cpp（逻辑回归测试 9/9 PASS）。
